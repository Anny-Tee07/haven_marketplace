# HAVEN 🏠

A simple and responsive real estate marketplace web application built as part of the **Tech With Chinaza 7-Day Building Challenge**.

## 📌 About The Project

HAVEN is a real estate marketplace MVP designed to provide users with a simple way to explore properties and find a place they'd love to call home.

The project is being developed from idea to implementation within seven days as part of the **7-Day Building Challenge** organized by the Tech With Chinaza community.

The goal is to build a functional MVP while improving my frontend development skills, practicing consistent GitHub contributions, and learning through hands-on development.

## ✨ Features

* Responsive navigation bar
* Hero section with property search
* Property listings
* Property type filtering
* Price range filtering
* Property details
* Responsive property cards
* Contact/enquiry functionality
* Mobile, tablet, and desktop responsiveness

## 🛠️ Technologies Used

* HTML5
* Bootstrap 5
* CSS3
* JavaScript
* Git & GitHub

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate into the project folder:

```bash
cd HAVEN
```

3. Open the project in VS Code.

4. Open `index.html` in your browser or run it using a local development server such as Live Server.
